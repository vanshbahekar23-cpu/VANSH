# VANSH — Creator × Brand Agency Website

## Files

- `index.html` — website structure and content
- `style.css` — design, responsive layout and animations
- `script.js` — mobile menu, scroll reveal and cursor effect

## Run in VS Code

1. Create a folder called `VANSH-Creator-Brand-Agency`.
2. Put `index.html`, `style.css`, and `script.js` inside it.
3. Open the folder in VS Code.
4. Install the **Live Server** extension by Ritwick Dey (optional but recommended).
5. Right-click `index.html` → **Open with Live Server**.

You can also simply double-click `index.html` to open it in your browser.

## Important

The “Sample Campaign” section is explicitly labeled as a concept, not a real client campaign. The site is intentionally positioned broadly so VANSH can work across creator niches and brand categories. Update it after you complete your first real collaboration.

To change text, edit `index.html`.
To change colors/design, edit `style.css`.
To change animations/interactions, edit `script.js`.
